MINECRAFT / COMBAT / v1.0

Nuclear StrikeThe essentials.

Choose a target on a terrain map, press the launch button, and send in a warhead. Or light Nuclear TNT for the same enormous blast.

Jump to crafting ↓

FIELD GUIDE

Getting started.

  1. Place a Nuclear Launch Button on a block.
  2. Right-click with the Targeting Map to open its terrain map. Click a location, then choose Save target.
  3. Carry the saved map and a Nuclear Warhead in your inventory.
  4. Right-click the placed launch button. A warhead descends onto the selected location. Survival consumes one warhead.

FIELD GUIDE

How it works.

  • The destruction sphere has an 80-block radius, or 160 blocks across. Nuclear TNT uses the same blast routine.
  • Place Nuclear TNT and ignite it with flint and steel or a fire charge. Redstone and nearby explosions can also prime it. Its fuse is eight seconds.
  • Blocks inside the sphere, including obsidian and liquids, are removed. Bedrock remains. Drops are suppressed. Terrain removal runs in batches over several seconds.
  • Entity damage reaches 1,000 near the center and decreases toward the edge.
  • The targeting map saves X/Z and dimension. Select within 4,096 blocks on each horizontal axis, in your current dimension and inside the world border.
  • North is up; cyan marks your location. Dark map cells represent unloaded terrain. Use the map’s zoom and directional controls.
  • The tntExplodes game rule disables both nuclear weapons when false. This mod changes large areas of terrain; use a test world or backup before experimenting.

FIELD GUIDE

Install the right build.

  1. Choose exactly one jar that matches your Minecraft version and loader.
  2. Install the required loader. Fabric and Quilt Boat Motors builds require matching Fabric API; native Forge and NeoForge Boat Motors builds do not. Other mods here currently require Fabric API.
  3. Put the mod in your profile’s mods folder. For multiplayer, install it on the server and every client.
  4. Fully restart Minecraft to load the mod.

FIELD GUIDE

Versions & loaders.

The current build is for Minecraft Java 26.3 / Fabric, with Java 25, Fabric Loader 0.19.5 or newer, and compatible Fabric API. Forge, Quilt, NeoForge, and other Minecraft versions have not been validated for this mod.

FIELD GUIDE

Common questions.

Why will the button not launch?

Save a target in your current dimension and carry the map and a warhead. Survival consumes a warhead per launch.

Why does the crater take time to finish?

Terrain removal is batched to reduce lag. Pending terrain work is saved and resumes after a normal world reload.

Where are the Creative items?

Look in the Redstone Blocks creative tab.
